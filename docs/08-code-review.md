## 故障依据、最小修复与回归范围

| 具体输入／操作 | 原实际失败方式 | 修复与必要检查 |
| --- | --- | --- |
| 两篇论文但语义字段／覆盖证据缺失 | 直接 completed，缺口与终止原因不实 | 仅 partial 阶段性资料；无可核查文本 failed；运行与报告原因一致 |
| 多次请求中暂停／取消 | 只有阶段末检查；游标丢失；旧 worker 快照覆盖控制状态 | 每次请求前检查、持久化已返回结果与游标；API控制状态保留 |
| 等待arXiv限流时暂停 | 提前计数，等待结束仍可能发请求 | 限流之后、HTTP之前回调；未发请求不计数 |
| 暂停追加信息后继续 | 补充从未处理；年份不参与检索 | 初始／当前输入分开；重新规划与纳入范围更新，不能解释则 needs_input |
| 补充规划给重复查询或省略历史选择 | 先排除历史，后停止；消息仍pending，旧资料误判failed | 选择明确；范围、选择、消息与游标原子保存；重复查询也处理已接受补充 |
| 请求数／时间达限 | 本地操作计数，模型可越限，没有总时限 | 所有实际HTTP边界计数，失败／跳转包含；剩余时间取消；暂停等待不计时 |
| 已发检索被总时限取消 | 用量已计但查询／错误记录丢失 | 只为实际发起的请求保留 execution_limit 记录 |
| 多任务／重复启动 | BackgroundTasks 并发；共享连接无互斥 | lifespan串行执行器、活动冲突、事务互斥与外键；不增分布式框架 |
| 重新获取论文／文本 | REPLACE覆盖历史，引用失效 | 每运行元数据快照、文本只追加；字符区间、页码、论文与引文一致 |
| 模型／检索错误及畸形响应 | 吞异常为空结果；未知token为0；Responses读错字段 | 已知错误分类、结构化输出入口校验、未知null、程序错误抛出 |
| PDF恶意重定向／DNS换绑／长解析 | 访问后验证，无可终止解析，错误伪造页1 | 逐跳先校验固定公网IP、保留TLS校验、限制大小／跳转；子进程超时与取消真实回收 |
| 空主题、非法年份、终态暂停、运行中补充 | 输入／状态约束不全 | 入口校验、409冲突、有限列表查询；所有终态不隐式重启 |
| 暂停请求后程序错误／进程退出 | 错误保存会被pause_requested覆盖，停在无法完成的暂停 | failed／interrupted保留；正常暂停和用户取消仍有对应语义 |
| 外部网页对本机发简单POST | wildcard CORS允许读任务，简单POST可能触发本地费用 | 精确本地Origin、拒绝跨站修改、Host校验；这不是完整身份认证 |
| Atom条目给javascript或外部域名链接 | URL流入可点击前端来源链接 | 官方HTTP(S)来源URL边界校验，错误条目拒绝，不执行任意模型URL |
| 前端过期／重叠轮询和服务失败 | 旧数据回写，空结果掩盖失败，状态遗漏 | AbortController＋版本校验＋非重叠setTimeout；错误可见、手动重试、10种状态与控制 |
| TypeScript生成配置同名JavaScript | Vite默认加载生成文件，源码配置可能被遮蔽 | 脚本显式选择TypeScript配置；生成文件保留但Git忽略；现有构建验证 |
| 原路由／工作流测试 | 正式数据库和全局Mock污染、隐含网络 | 临时数据库／内存库、注入实例与替身；不读取本地凭据文件或发付费请求 |

核心复现命令（仓库根目录）：

```bash
PYTHONPATH=. .venv/bin/python -m pytest tests/test_storage.py tests/test_workflow_engine.py tests/test_api_tasks_and_runs.py tests/test_api_health.py -q
```

实际遇到的回归失败：Python 3.9中在运行循环外构造asyncio.Lock，使首次asyncio.run之后其他引擎初始化失败；改为首次执行时在当前循环构造，随后工作流回归通过。没有靠跳过用例、伪造成功或修改用户数据库绕过。

前端构建产物保留；同名Vite生成文件不删除，脚本明确读取源码配置。用户已有改动、密钥与真实运行数据未清理，未暂存或提交Git。
