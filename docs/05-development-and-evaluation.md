# 开发计划与评估方案

状态：计划；无实现、运行结果或经过验证的质量数值。

## 里程碑

| 阶段 | 输入／操作 | 输出 | 完成标准 |
| --- | --- | --- | --- |
| M0 环境与选型 | 确认云端模型服务、数据发送边界；在目标网络访问 arXiv | 配置样例、锁文件、实际启动说明 | 可复现安装；可用源和模型的实际条件已记录 |
| M1 任务与界面 | 建立前后端、SQLite、任务和运行接口 | 对话式输入、创建、查看、启动、暂停、补充、继续、取消和历史页面 | 状态可查询，重启后历史仍在；无真实模型时可用明确标记的固定样本开发 |
| M2 检索与内容 | 接一个真实检索源、去重、摘要及允许访问的 PDF 文本提取 | 论文列表、查询记录、实际读取范围 | 真实来源可追溯，读取失败和缺项可见 |
| M3 智能体 | 理解、规划、提取、充分性与有限迭代；接入三种模型协议 | 可观察的状态机、执行限制和用量统计 | 指定缺口触发新查询；暂停后补充并继续不丢历史；上限停止，记录原因 |
| M4 综合与报告 | 有证据地比较、生成报告及 Markdown、Word 和 PDF | 报告、引用和导出 | 关键事实可定位；不可比与缺口显式展示，三种格式内容一致 |
| M5 评估与交付 | 固定样本与真实案例评估、人工复核 | 指标结果、示例报告、运行文档 | 公开样本、口径、结果和失败案例，完成 FR-01 至 FR-12 的验收 |

日期及工期取决于人员、模型和网络条件，当前不臆定。每阶段可在其依赖就绪时部分并行。

## 必要测试

针对核心规则设计少量行为测试，固定样本和模型／检索替身用于可复现执行，不连接付费服务：

1. 相同 DOI 的跨源记录合并；仅标题近似时保留疑似项，论文版本差异不被抹掉。
2. 摘要未提及的数据集或数值保持缺失，证据只定位到实际读取文本；无效引用不得成为报告事实。
3. 一个子问题缺口触发新查询；无新增结果、轮次或调用上限触发停止，并保留已有成果和原因。
4. 暂停在外部请求结束后生效；补充范围后重新评估，继续保留运行标识、历史证据和累计用量，不把不再相关的论文纳入新报告；取消和重启中断的状态符合约定。
5. 可比较与不可比较的实验设置得到不同标记；PDF 读取失败不会被当作全文已读；三种导出格式包含同一组来源和缺口。
6. 三种模型协议分别使用可控的接口样例验证请求、响应和错误转换，不假定第三方兼容服务支持全部可选能力。

具体测试框架和命令等工程创建后确定。无需为了每次修改增加冒烟测试；文档变更核查链接和内容即可。

## 质量评估设计

先选多个不同子领域、明确时间范围及子问题的公开课题，建立人工标注的候选论文集与证据样本。明确标注者、检索范围和纳入标准；样本不等于领域全部论文。建议至少两名评审独立核查分歧，人员不足时如实说明单人评估限制。

| 指标 | 计算方法 | 边界 |
| --- | --- | --- |
| 检索精确率 | 人工判定相关的系统返回论文数 / 人工检查的返回论文数 | 对应具体主题和结果截断数 |
| 样本召回率 | 系统找到的标注相关论文数 / 标注相关论文总数 | 只能代表标注样本，不代表全库召回 |
| 子问题覆盖率 | 至少有一篇人工确认相关论文的子问题数 / 子问题总数 | 不证明研究方向已全面覆盖 |
| 字段准确率 | 与原文一致的已抽查字段数 / 已抽查字段数 | 分别统计摘要和全文；缺失单独统计 |
| 引用支持率 | 原文确实支持主张的抽查引用数 / 抽查引用数 | 有效链接和文本位置不等于语义支持 |
| 运行消耗 | 每任务墙钟时间、外部请求数、模型调用数、可得 token 与费用 | 缺乏计量的字段标未知，记录环境和服务 |

记录抽样方式、分母、原始判断和冲突案例；不把模型自评分当作准确率。分别统计充分终止、执行限制终止、来源失败和解析失败比例。阈值及通过标准在确定验收要求和建立基线后制定，不先虚构达标线。

示例报告需注明研究问题、检索日期、数据源、时间范围、纳入与排除原因、来源快照／链接、证据缺口和人工复核情况。只提交允许公开的样本与报告。
